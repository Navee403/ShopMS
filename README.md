# 🛍️ Shop MS

A full-stack MERN shop application for managing products with a React frontend, Express/Node.js backend, and MongoDB database.

## Features

- Product listing
- Add products
- Edit products
- Delete products
- REST API
- MongoDB database
- React + Vite frontend

## Tech Stack

- React
- Vite
- Node.js
- Express
- MongoDB
- Mongoose
- JavaScript

## Project Structure

```text
ShopMS/
├── client/
└── server/
```

## Local Development

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
node server.js
```

> MongoDB must be running locally for the backend to connect.
